# v0.21.0 — release verification

Released on 2026-11-02 on the maintainer's instruction to ship before a full
dev test ("ship now test later"). Scope: another as one place for every
coding-agent session. Project-scoped CLI defaults, readable session excerpts,
a read-only MCP server and @-mention adapters for Claude Code, OpenCode V2 and
Qwen Code, dynamic titles, Qwen Code title hooks, and corrective retries in the
OpenCode title plugin. The Pi @ extension, the Codex skill install, and the
Antigravity check (slice 5 of the plan) are not part of this release.

## Regression and runtime checks

- Go race suite, vet (including `GOOS=windows`), lint, and the OpenCode
  plugin's 27 tests plus typecheck passed on the combined branch.
- The first Windows CI run failed because the checkout converted the embedded
  `SKILL.md` to CRLF. `.gitattributes` now keeps `integrations/**` LF, so every
  build embeds the same bytes; the rerun passed.
- Live checks: `claude mcp get another` connected; `opencode mcp list` connected
  and `list_mcp_resources`/`read_mcp_resource` returned 50 sessions and the
  bounded excerpt; `qwen mcp list` connected against an isolated `QWEN_HOME`;
  OpenCode loaded the `another` skill from `~/.config/opencode/skills/another`.
- Not verified: an `@` selection inside Claude Code or Qwen Code, and
  `@another` used from an OpenCode prompt. OpenCode V2's `@` picker omits MCP
  resources (anomalyco/opencode#61071), which is why the skill exists.
- The six-agent end-to-end regression pass was not run for this release.
- Native Windows runtime was covered by CI only.
