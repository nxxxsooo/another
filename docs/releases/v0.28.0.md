## Integration boundary

The `/ref` slash command is a client-local TUI keymap registration. OpenCode's
`GET /api/command` lists server commands and currently returns zero `ref` entries;
it cannot verify a TUI-only slash command. Do not add a fake server command just
to change that count. Verify the active server/TUI plugin and actual slash-menu
ownership instead, and report this API inventory limitation explicitly.

The current MCP command is inspected before installation and must remain
byte-for-byte unchanged. The released installer can target an isolated
`--config-dir`; its owned sessions bundle can then be installed into the real
plugin directory without rewriting the independent MCP entry.
