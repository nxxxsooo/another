## Regression plan and evidence

- 46 TypeScript adapter tests and typecheck passed locally, including recovery
  budgets across reloads, manual renames, location/workspace ownership, late
  results, and screenshot context. Both native CI jobs now run these checks.
- Full Go tests and vet passed locally; integration race checks passed.
- The six continuously tested providers — Pi, OpenCode, Claude Code, Codex,
  Antigravity, and Qwen Code — are covered by the full provider test suite;
  release preflight also checks native detection and installed CLI versions.
- Native preflight passed for all six: Pi 1.5.0, OpenCode 2.2.5, Claude Code
  2.1.299, Codex 0.166.0, Antigravity 1.4.12, and Qwen Code 0.26.7. Each data
  root and CLI was detected, and every version command exited successfully.
- Live OpenCode 2.2.5: a controlled 503 title failure recovered after the first
  completed turn. Only the owning location generated the recovery title with
  17 locations loaded. A screenshot-only opening was renamed from its initial
  generic title using the assistant's explanation. Disposable sessions and
  temporary failure injection were removed after verification.
- `another-dev` matched the tested build and carried `+dev`. The `adev` alias
  resolved to it in an interactive shell with terminal-proxy autostart omitted
  from the headless check.
- Native Windows plugin execution inside OpenCode has not been exercised;
  Windows CI will validate the adapter harness and filesystem behavior.
