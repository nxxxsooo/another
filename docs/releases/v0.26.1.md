## Installation caveats

- Integration status compares the MCP executable with the binary running the
  check. After preserving the requested development MCP command, released
  `another integrations status --kind recall` reports `outdated (unknown version)`;
  `another-dev integrations status --kind recall` reports `installed`. The skill
  itself is current. This is an executable-name mismatch, not a stale skill.
- `make install` succeeded but its automatic alias check was skipped because
  interactive zsh startup failed without a terminal. A pseudo-terminal retry
  timed out. Existing `a='another'` and `adev='another-dev'` definitions remain
  present; their interactive execution was not verified for this release.
