# v0.24.3 — release verification

Released on 2026-11-07 as a patch release for the optional OpenCode title
plugin. It no longer creates a temporary title-agent session per request
(introduced in v0.24.1 to keep gateway authentication). The first title
rewrites OpenCode's own title request in the `title` hook; repairs,
corrections, and refreshes call `session.generate` on the session itself with
a `generate` hook that strips the request to the title prompt.

## Regression and runtime checks

- Plugin: `npm test` (49 tests) and `npm run typecheck`; full Go suite.
- Live run on an isolated OpenCode 2.2.5 server with a session-hook gateway
  plugin: the first title arrived in one `title` request (about 1.5 KB, title
  model, final dated answer, no second rename); a refresh after three turns
  took one `generate` request (about 1.7 KB). The v0.24.1 path sent roughly
  113 KB of agent context per title call.
- Found while testing: inside a plugin, `session.update({ title: "" })`
  renames to an empty title instead of regenerating, unlike the HTTP route,
  so the plugin does not use it.
- Only the OpenCode plugin changed; the six continuously tested providers are
  covered by the unchanged provider suite in CI.
