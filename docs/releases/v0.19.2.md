# v0.19.2 — release verification

Released on 2026-10-12. One feature: an action history. Every archive, delete,
and rename another performs is recorded, and `h` opens the list — newest first,
one entry per change, with `enter` to reverse the selected one through the
agent's own native operation. A delete is reversed by putting the removed bytes
back exactly as they were, so another now keeps a bounded copy of deleted
sessions under `~/.cache/another/history/`: the newest fifty, for thirty days.
Past that, the entry stays listed but is marked no longer recoverable, and its
bytes are gone. Where an agent cannot hand the bytes back, its delete is still
recorded and shown, marked not reversible — the copy is never re-rendered from
another's model.
