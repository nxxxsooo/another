# v0.19.3 — release verification

Released on 2026-10-12. One feature: Antigravity gains its own title adapter.
The second setup page gains an `Antigravity title hooks` row, and
`another integrations install agy` installs the adapter outside setup: another
merges a Stop hook group into Antigravity's shared `hooks.json`
(`~/.gemini/config/hooks.json`), and at the end of an idle turn the hook pipes
the conversation id to `another rename --hook-stdin`, which asks the configured
title agent to name that conversation under the same MMDD｜Type｜Topic policy
every other agent follows. Groups other tools wrote into the shared file —
Hindsight's included — are preserved untouched; a hook another did not write is
reported and never claimed without `--force`, and a hook document another
cannot parse is refused outright because a merge would destroy what it cannot
carry over. Hooks fire only in interactive sessions (`--print` runs no hook
events); while a continuation is queued the rename waits for the next idle turn.
