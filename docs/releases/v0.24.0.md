# v0.24.0 — release verification

Released on 2026-11-05 as a minor release for short time windows in the
session browser: `t` now narrows through 90 days → 30 → 7 → 3 → 48h → 24h →
all time, and `T` walks the same stops back. Windows stay rolling (now minus
whole days, by each session's last message), so the stops under three days
are named in hours. Shipped right after v0.23.0, sequenced so its website and
Homebrew verification finished first.
