# v0.30.2 — release verification

Single and bulk rename report empty output, invalid titles, and subprocess
errors separately. Exit status and a short diagnostic are shown when available.
The single rename box wraps the explanation; in the batch review, expanding
the failed rows shows the reason below the title. Explicit `KEEP` is still
honored by automatic title hooks.
