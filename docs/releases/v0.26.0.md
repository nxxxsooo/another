## Regression plan and evidence

- All six continuously tested providers enter the regression pass: Pi,
  OpenCode, Claude Code, Codex, Antigravity, and Qwen Code. Full local
  `go test ./...`, `go test -race ./...`, and `go vet ./...` passed.
- `golangci-lint run ./...` reports zero issues; `goreleaser check` passed.
- Focused Windows runtime tests passed for named Guardian classification,
  project metadata precedence and fallbacks, path boundaries, case and extended
  prefixes, metadata-only refresh, index/search behavior, and list rendering.
- A temporary isolated index against the real Windows Codex corpus showed no
  Guardian rows by default, exposed reviews with `--include-subagents`, resolved
  ChatGPT-backed project labels, and left the projectless `new-chat` path alone.
  Native records and the released installation were not changed by this check.
- Full Windows/race CI is a publication gate. Interactive TUI operation and live
  native handoffs for all six providers have not been repeated for this release;
  renderer regressions and provider tests do not claim that coverage.
