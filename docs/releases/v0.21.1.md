# v0.21.1 — release verification

Released on 2026-11-02 as a patch for two regressions in v0.21.0 that the
ChatGPT Codex review bot flagged as P1 on #48 after it merged. Fixes landed in
#49: new Pi sessions get automatic titles again (an unnamed session's
first-prompt placeholder was read as a hand-set title), and reinstalling the
Qwen Code title hook keeps neighbouring hooks in its `Stop` entry.
