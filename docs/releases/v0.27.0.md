# v0.27.0 — release verification

Target: the accepted optional Herdr integration for local OpenCode sessions.
Uppercase `H` focuses an exact live native-session match or opens the saved
session in a new local Herdr tab, keeping another open. `Enter` remains the
native current-terminal resume action. No settings or hooks are installed.

## Regression plan and evidence

- Full provider regression includes Pi, OpenCode, Claude Code, Codex,
  Antigravity, and Qwen Code. No live native agent handoffs are claimed.
- Local full Go tests, race tests, vet, lint (zero issues), and Windows
  cross-compilation passed during dev testing. Release-commit CI remains the
  native Windows gate.
- Herdr tests cover exact native IDs, ambiguous matches, remote exclusion,
  partial discovery, stale records, explicit local-space selection, command
  failures, deadlines, quoted native resume argv, asynchronous TUI behavior,
  pending-action mutation guards, and unchanged ordinary Enter behavior.
- Installed development TUI smoke verified a real live marker. Existing
  `adev='another-dev'` and `a='another'` aliases were executed successfully in
  interactive zsh with terminal-proxy detection disabled for that subprocess.
  Installed development bytes matched the tested build; released binary stayed
  unchanged during development testing.

## Known limitations

- Some live OpenCode terminals do not report native session records. Such
  incomplete discovery intentionally blocks new-tab launches while retaining
  known exact matches for focus. This is not a claim of atomic duplicate-launch
  prevention.
- Focusing a shared terminal does not select its internal OpenCode session tab.
- Real Herdr focus/tab actions and native Windows Herdr interaction were not
  exercised during development; deterministic command fixtures cover these
  actions without changing the user's visible workspace.
