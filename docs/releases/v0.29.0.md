## Regression and compatibility evidence

- Full local Go tests, race, vet, lint (zero issues), format, Windows
  cross-build/vet, GoReleaser config validation, and shell installer syntax
  passed. OpenCode sessions (30 tests) and title policy (49 tests) both passed
  their local tests and typechecks. Both GitHub CI jobs passed on the tagged
  commit, including native Windows Go/Node and PowerShell syntax checks.
- Provider regressions covered Pi, OpenCode, Claude Code, Codex, Antigravity
  and Qwen Code. The published binary found a sample native session for each
  except Claude Code, for which it found an isolated JSONL fixture; no live
  Claude Code store was present. The CLI smoke used a separate config/cache.
- Development probes used throwaway OpenCode 2.3.2 sessions to verify
  reversible archive, single and marked-list refresh, external archive
  reconciliation on startup, and WAL-only changes with a symlinked database.
  All probe sessions were deleted.
- Range tests cover both directions across pages, group headers, filtered
  order, page-toggle fallback, and clearing the anchor.
- Portfolio `npm run build` passed, including the analytics coverage check.

## Known limitations

- Native Windows passed CI, but neither live OpenCode archiving on Windows
  or Linux nor a Homebrew/Linux or PowerShell/Windows consumer install was
  exercised. Live OpenCode archive and the consumer upgrade were on macOS.
- The six release-tested providers were covered; this release does not add
  an end-to-end test requirement for compatibility adapters such as Doubao.
