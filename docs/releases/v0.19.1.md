# v0.19.1 — release verification

Released on 2026-10-12. One change: a title suggestion now also reads the end
of a long session. Suggestions used to see only the opening exchange, which is
where intent starts — but a session long enough to overflow the prompt often
says what it turned out to be about only at the end. The last messages are now
carried alongside the first ones, within the same size budget as before.
