# v0.30.0 — release verification

The TUI goodbye now uses the landing page’s pixel wordmark. The mint copy
slides in from the right and settles behind the violet face. The terminal
shows a compact banner below 87 columns and a still image when motion is
disabled.

Release CI includes Linux and native Windows race suites, including the
provider packages for Pi, OpenCode, Claude Code, Codex, Antigravity, and Qwen
Code. No native agent configuration changes are needed for this release.
The published macOS cask was exercised in an isolated terminal: 10 in-place
redraws at 87 columns, no redraws with `ANOTHER_NO_MOTION=1`, and the compact
banner at 80 columns. Linux and Windows consumer installs were not exercised.
