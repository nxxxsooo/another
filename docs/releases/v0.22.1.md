# v0.22.1 — release verification

Released on 2026-11-03 as a patch for v0.22.0's session links:
`another tui <session-id>` now opens that session's preview, as space does,
instead of only placing the cursor on it in the list, which made a link from
toodo look like it had done nothing. Esc returns to the list with the session
still selected.
