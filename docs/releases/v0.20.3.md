## Regression and runtime checks

- Full scoped-commit race suite, vet, and lint passed locally, covering Pi,
  OpenCode, Claude Code, Codex, Antigravity, and Qwen Code. Linux and Windows CI
  both passed full tests and race tests. The Codex regression uses a native
  subprocess fixture on Windows and Unix, without shell-script mocks.
- Read-only native discovery succeeded for all six maintained providers.
  The audit also reported pre-existing index-count differences for OpenCode,
  CodeM, and Antigravity; this was not a complete live lifecycle regression for
  every provider.
- Native Codex `thread/name/set` followed by `thread/read` verified the affected
  session, and another's refreshed index matched. The maintainer confirmed
  the fix worked in ChatGPT Desktop; no claim is made about immediate repaint
  without a list reload.
- Native Windows desktop validation was not performed locally; Windows CI
  verified subprocess and protocol behavior before tagging.
- Temporary diagnostic hooks were removed after reporting code-signing
  rejection. Existing unrelated hooks were restored unchanged.
- Website production build and analytics guard passed. Headless checks saw one
  correct Umami tracker and successful pageview requests on all three routes;
  install-copy, GitHub, and Releases click events each emitted once with 200
  responses. Hydrated client-side navigation emitted a successful pageview
  without replacing the document.
- Global `brew update` reported unrelated tap errors, but refreshed the public
  project tap. The targeted upgrade succeeded with automatic updates disabled.
- Interactive-shell startup prevented verification of `adev`/`a` execution;
  their existing definitions were inspected and left untouched. Direct binary
  paths and versions were verified.
