# v0.30.1 — release verification

OpenCode V2 title runs send the full prompt on stdin, preserving the selected
launcher and its configuration. A Windows `.cmd` launcher had truncated the
argument at the first newline. The batch review now counts missing suggestions
as failures instead of unchanged titles.
