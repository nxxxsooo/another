# v0.20.2 — release verification

Released on 2026-10-28. One fix: a refresh no longer fails with `database is locked (5) (SQLITE_BUSY)` when it overlaps another writer to the index (the background content indexer, a second refresh, or another process). The index opens with `_txlock=immediate`, so each transaction takes the write lock at `BEGIN` and waits under `busy_timeout` instead of failing on the read-to-write upgrade.
