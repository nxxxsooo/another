# v0.22.0 — release verification

Released on 2026-11-03 as a minor release for one new command form:
`another tui <session-id>` opens the browser on that session from any
directory. The linked session is added to the page when the scope, recent
window, or page would leave it out, and the first key press hands the list back
to the person's scope and search. toodo uses it to jump from a task to the
conversation it came from.
